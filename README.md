## 📌 About the Repository

This repository contains the Python implementations and corresponding experiment outputs for all **18 laboratory experiments** of **UCM02 – Mathematical Foundations of Computer Science**.

The experiments demonstrate how mathematical concepts are applied to computational problems through practical Python programs. They cover mathematical logic, set theory, functions, relations, recurrence relations, recursion, graph algorithms and tree structures.

Each experiment is organised to support easy access to the source code and its corresponding output.

## 🎯 Objectives

- Understand the mathematical foundations used in computer science.
- Implement propositional and predicate logic using Python.
- Perform set operations and analyse mathematical functions and relations.
- Understand recurrence relations and recursive problem-solving.
- Apply graph traversal and optimisation algorithms.
- Implement tree structures and graph-based algorithms.
- Develop logical reasoning, computational thinking and programming skills.

## ⚙️ Installation and Execution

### 1. Install Python

Download and install Python 3:

[https://www.python.org/downloads/](https://www.python.org/downloads/)

Verify the installation:

```bash
python --version
```

### 2. Clone the Repository

```bash
git clone https://github.com/visvajeet-s05/UCM0201-Lab-Experiments-1931260007.git
```

### 3. Navigate to the Repository

```bash
cd UCM0201-Lab-Experiments-1931260007
```

### 4. Open the Source Code Folder

Navigate to:

```bash
cd Experiment_Coding
```

### 5. Execute an Experiment

Run the required Python file using:

```bash
python filename.py
```

Replace `filename.py` with the actual Python filename of the experiment you want to execute.

**Note:** The exact filenames should be selected from the `Experiment_Coding` folder. Some experiments may request input through the terminal.
